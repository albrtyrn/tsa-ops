# WORKFLOW: Advanced Integrations

## In-Scope Features
1. **Recipe ↔ Menu Integration:** Link the `dishes` (menu) table directly to a `recipes` library, allowing users to pull standard recipes (ingredients, instructions, costs) into event menus rather than creating dishes from scratch every time.
2. **Drivers ↔ Grocery Runs Integration:** Create a unified view or linkage between the `staff_members` (Drivers) and the `grocery_runs` tables, enabling assignment of volunteers with cars to specific grocery trips.
3. **Enhanced Analytics Dashboard:** Implement a dedicated analytics page showcasing historical budget variances, attendance trends, and volunteer retention using chart components (e.g., Recharts).
4. **AI Features:** Implement AI-driven plan generation. Wire the decorative "Generate Plan (AI)" button in the event header to a server action that calls an LLM API to suggest timelines, shopping lists, or menus based on the event description and headcount.

## Business Logic Rules
- Recipes added to an event menu should copy the data (or link with a specific snapshot) so that modifying the master recipe does not inadvertently alter past event records.
- Only confirmed staff members with the `Driver` capability/role can be assigned to grocery runs.
- The AI Plan Generator must explicitly indicate which items were generated by AI and allow the user to review and approve them before saving to the database.

## Out-of-Scope Table
| Category | Excluded Item | Reason |
| :--- | :--- | :--- |
| **Features** | AI Image Generation for Recipes | Focus solely on text-based planning (timeline, shopping). |
| **Backend** | Real-time WebSockets | Data can be fetched via standard SSR or polling. |
| **Refactoring** | Major database restructuring | Add new relations/tables (like `recipes`), but do not break existing tables. |

## Steps
1. **Database Schema:** Create `recipes` table and link it to `dishes`.
2. **Recipe Library UI:** Build a dedicated page to manage the master recipe library.
3. **Menu Integration:** Update the event Menu tab to allow importing from the recipe library.
4. **Driver Integration:** Update the Grocery Runs tab to populate a dropdown of eligible drivers from `staff_members`.
5. **Analytics Dashboard:** Build `app/analytics/page.tsx` and integrate chart components.
6. **AI Integration:** Implement the `generatePlan` server action and wire the button in `event-header.tsx`.
